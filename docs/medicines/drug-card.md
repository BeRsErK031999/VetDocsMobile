# Карточка препарата

Документ задает единый формат для справочных карточек препаратов.

## Структура карточки

1. Международное и торговые названия.
2. Форма выпуска и концентрация.
3. Показания, противопоказания и ограничения.
4. Диапазоны дозировок по видам животных.

## Важно

Перед применением сверяйте дозировку с актуальной инструкцией, состоянием пациента и внутренними протоколами клиники.
